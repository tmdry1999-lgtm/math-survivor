# Math Survivor

초등 저학년(1학기) 수학 단원을 소재로 한 뱀서라이크(살아남기형) 웹 게임입니다. 이동하며 몰려오는 적을 자동공격으로 처치하고, 레벨업 시 등장하는 수학 문제를 맞히면 무기/스탯 업그레이드를 받는 방식으로 진행됩니다. Phaser 3 + Vite 기반이며, Vercel에 배포되어 있습니다.

- 배포 주소: https://math-survivor.vercel.app
- 로컬 개발: `npm install` → `npm run dev`
- 테스트: `npm test`
- 빌드: `npm run build`

## 프로젝트 구조

```
src/
  main.js              # Phaser 게임 부트스트랩
  scenes/              # BootScene, TitleScene, HubScene, StageScene, QuestionScene, PauseScene, ResultScene
  systems/             # QuestionEngine(문제 생성), SaveManager(저장), SfxPlayer(효과음)
  data/                # units.js(단원 정의), weapons.js(무기), cosmetics.js(허브 꾸미기)
  ui/                  # panelStyle.js(공용 UI 패널 스타일)
  assets/sprites/      # 캐릭터/적/무기/데코 픽셀 아트
docs/design/           # 게임 기획서, 단원별 문제 설계 문서
tests/                 # vitest 테스트
```

## 개발 히스토리로 본 요청 경향

지금까지의 커밋 히스토리를 주제별로 분류하면 대략 다음과 같습니다.

| 분류 | 예시 |
| --- | --- |
| **UI/비주얼 연출** | 청키 버튼 그림자, 캐릭터/적 발밑 그림자, 픽셀 아트 그래픽 교체, HUD 타격감 강화, 허브 화면 확장, 화면 중앙 정렬 버그 수정 등 |
| 문제(퀴즈) 콘텐츠/난이도 | 단원별 문제 유형 추가, 도형 단원 문제, 스테이지 진행에 따른 난이도 상승, 문제 팝업에 별점/보상 아이콘 추가 |
| 전투/무기 시스템 | 무기 8종 + 진화 시스템, 업그레이드(연사속도/사거리/다중사격), 적 3종 다양화, 아레나 확장 |
| 스테이지 길이/난이도 밸런스 | 스테이지 길이 조정(120초 → 4분 30초 목표), 단원 즉시 해금 |
| 코어 시스템/인프라 | SaveManager, StageScene 기본 루프, 결과 화면-저장 흐름 연결 |

**요약:** 가장 많이 요청하고 반복적으로 다듬어 온 부분은 **UI/비주얼 완성도(연출, 그래픽 교체, 레이아웃 버그 수정)**이며, 그 다음으로 **문제(퀴즈) 콘텐츠와 난이도 곡선**에 대한 요청이 많았습니다. 전투/무기 시스템은 게임성을 깊게 만드는 방향으로 꾸준히 확장되어 왔습니다.

## 주요 변경 이력 (최신순)

- 단원마다 문제 유형을 2종으로 늘려 다양성 확보
- 화면 중앙 정렬 버그 수정, ESC 일시정지 메뉴 추가, 무기 그래픽을 도트 스프라이트로 교체
- 무기 8종 + 진화 시스템으로 전투 깊이 확장
- 이동 중 캐릭터가 끊겨 보이던 문제 수정
- 문제 팝업에 난이도 별점과 보상 미리보기 아이콘 추가
- 참고 이미지의 뱀서라이크 HUD/타격감 스타일로 스테이지 화면 강화
- UI 패널/버튼에 그림자를 넣어 입체감 있는 청키 버튼 스타일 적용
- 캐릭터/적 발밑에 그림자 추가로 공중에 뜬 느낌 제거
- 이모지 아이콘을 픽셀 아트로 교체하고 타이틀/결과 화면 연출 강화
- 스테이지 진행에 따라 문제 난이도가 실제로 올라가도록 구현
- (전체 이력은 `git log`로 확인 가능)
