# Tiny Dungeon (Kenney)

Source: https://kenney.nl/assets/tiny-dungeon — CC0 (public domain, free for any use, no attribution required).

Kept here as the full raw tile set so future work (more enemy variety, environment tiles, etc.) can pick additional sprites without re-downloading. Only `tile_0096.png` (knight -> player) and `tile_0108.png` (slime -> enemy) are currently wired into the game, copied into `src/assets/sprites/`.
