# 단원별 문제 설계 (1학년 1·2학기, 2022 개정 교육과정)

각 단원은 게임 내 스테이지 1개에 대응한다. 모든 문제는 **숫자·기호·그림 중심**으로 표현하며, 텍스트는 최소화한다.

---

## 1학기

### 1. 9까지의 수 (`nums_within_9`)
- **문제 유형**
  - 그림 개수 세기: 사과 그림 N개를 보여주고 알맞은 숫자 고르기
  - 숫자 → 그림 대응: 숫자를 보여주고 그 개수만큼 그려진 그림 고르기
  - 수 순서: 빈칸에 들어갈 다음/이전 수 고르기 (예: 3, 4, ?, 6)
- **생성 파라미터**: 1~9 범위 정수
- **보기 구성**: 정답 1개 + 오답 2개(±1~2 차이)

### 2. 여러 가지 모양 (평면도형) (`shapes_2d`)
- **문제 유형**
  - 세모/네모/동그라미 중 제시된 도형과 같은 모양 찾기
  - 여러 물건 그림(문, 시계, 삼각자 등) 중 특정 모양과 같은 것 고르기
- **생성 파라미터**: 도형 종류(세모/네모/동그라미) 무작위 출제
- **보기 구성**: 그림 3개 중 모양이 같은 것 1개

### 3. 덧셈과 뺄셈 (한 자리 수) (`add_sub_within_9`)
- **문제 유형**
  - 모으기/가르기: 그림 두 묶음을 보여주고 합 고르기
  - 덧셈식: `a + b = ?` (a+b ≤ 9), 그림으로 보조
  - 뺄셈식: `a - b = ?` (a, b ≤ 9, 결과 ≥ 0)
- **생성 파라미터**: a, b ∈ [1,8], 합/차 결과가 0~9 범위
- **보기 구성**: 정답 1개 + 오답 2개(±1~2)

### 4. 비교하기 (`comparison`)
- **문제 유형**
  - 길이: 막대/끈 그림 두 개 중 더 긴 것 고르기
  - 무게: 시소 그림으로 더 무거운 쪽 고르기
  - 넓이: 도형 두 개 중 더 넓은 것 고르기
  - 들이: 컵/그릇 그림 중 물이 더 많이 담긴 것 고르기
- **생성 파라미터**: 비교 속성별로 시각적 크기 차이를 명확하게(작은 차이 지양, 1학년 수준 고려)
- **보기 구성**: 그림 2개 중 1개 선택 (더 김/짧음, 무거움/가벼움 등 매번 다르게 질문)

### 5. 50까지의 수 (`nums_within_50`)
- **문제 유형**
  - 두 자리 수 읽기: 숫자를 보여주고 같은 수만큼 묶음(10개씩 묶음+낱개) 그림 고르기
  - 수 순서: 10 단위로 뛰어 세기 (예: 10, 20, ?, 40)
  - 두 수 비교: 두 숫자 중 더 큰(작은) 수 고르기
- **생성 파라미터**: 1~50 범위 정수
- **보기 구성**: 정답 1개 + 오답 2개(±1~5 차이, 자릿수 헷갈리는 오답 포함 가능)

## 2학기

### 6. 100까지의 수 (`nums_within_100`)
- **문제 유형**
  - 두 자리 수 읽기(10개씩 묶음 + 낱개 그림 → 숫자 고르기)
  - 뛰어 세기: 1씩, 10씩 뛰어 세기
  - 두 수 비교(<, >）
- **생성 파라미터**: 1~100 범위 정수
- **보기 구성**: 정답 1개 + 오답 2개

### 7. 덧셈과 뺄셈(1) — 받아올림/받아내림 없는 두 자리 수 (`add_sub_2digit_simple`)
- **문제 유형**: `(몇십몇) + (몇)`, `(몇십몇) + (몇십몇)`, 뺄셈도 동일 (받아올림/받아내림 없음)
- **생성 파라미터**: 각 자리 합이 10을 넘지 않도록 제한
- **보기 구성**: 정답 1개 + 오답 2개(자리 계산 실수형 오답 포함)

### 8. 여러 가지 모양 (입체도형) (`shapes_3d`)
- **문제 유형**
  - 상자 모양/공 모양/둥근기둥 모양 분류
  - "굴러가는 모양"과 "쌓을 수 있는 모양" 구분
- **생성 파라미터**: 입체도형 종류 무작위 출제
- **보기 구성**: 그림 3개 중 같은 모양 1개 고르기

### 9. 덧셈과 뺄셈(2) — 세 수의 계산 / 10 만들기 (`add_sub_make10`)
- **문제 유형**
  - 세 수의 덧셈: `a + b + c = ?`
  - 10이 되는 더하기: `? + b = 10`
  - 10에서 빼기: `10 - a = ?`
- **생성 파라미터**: a,b,c는 10 이하, 결과가 자연스러운 범위
- **보기 구성**: 정답 1개 + 오답 2개

### 10. 시계 보기와 규칙 찾기 (`clock_and_pattern`)
- **문제 유형**
  - 시계 그림을 보고 "몇 시" 또는 "몇 시 30분" 고르기 (1학년 수준: 정시/30분 단위만)
  - 규칙 찾기: 반복되는 도형/색깔 패턴에서 다음에 올 것 고르기
- **생성 파라미터**: 시각은 1~12시 정시 및 30분 단위만, 규칙은 2~3개 요소 반복
- **보기 구성**: 정답 1개 + 오답 2개(시침/분침 헷갈리는 오답 포함)

### 11. 덧셈과 뺄셈(3) — 받아올림/받아내림 있는 계산 (`add_sub_carry`)
- **문제 유형**: 받아올림이 있는 두 자리 수 덧셈, 받아내림이 있는 두 자리 수 뺄셈
- **생성 파라미터**: 결과가 100을 넘지 않는 범위, 받아올림/받아내림이 실제로 발생하는 조합만 생성
- **보기 구성**: 정답 1개 + 오답 2개(받아올림/받아내림을 빠뜨린 전형적 실수형 오답 포함)

---

## 공통 규칙 요약

| 항목 | 규칙 |
|---|---|
| 보기 개수 | 기본 3개 (정답 1 + 오답 2) |
| 오답 설계 | 전형적인 실수(자리 헷갈림, ±1~2 차이 등)를 반영해 학습 효과를 높임 |
| 텍스트 사용 | 숫자/기호/그림 우선, 보조 설명은 한 줄 이내 |
| 난이도 진행 | 같은 스테이지 내에서도 초반→후반으로 갈수록 숫자 범위·자릿수 난이도 상승 |
| 데이터 형식 | 단원별 JSON 템플릿 파일로 관리 (게임 로직과 분리) |
